# Työaikaseuranta

Työaikaseuranta on verkkosovellus, jonka avulla voidaan hallita tiimejä ja kirjata työntekijöiden työtunteja.

## Ominaisuudet

- Tiimien luominen ja tarkastelu
- Tiimin jäsenten tietojen näyttäminen
- Työtuntien kirjaaminen
- Raporttien tarkastelu
- Responsiivinen käyttöliittymä

## Toteutus

Projekti on toteutettu HTML:llä, CSS:llä ja JavaScriptillä. Käyttöliittymässä on kolme pääosiota: Tiimit, Kirjaus ja Raportit.

Projekti on toteutettu itsenäisenä kouluprojektina.
